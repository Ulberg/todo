Users created in the portal have no "usage location" by default. Microsoft won't assign a license without one, because which services are available depends on the country.

How to fix it:

1. Go to entra.microsoft.com → Entra ID → Users → Endre Ulberg (Admin) → Properties → Edit properties.
2. Open the Settings tab, set Usage location to Norway (or the country you're in), and save.
3. Assign the license again under the user → Licenses → Assignments → Add, or from admin.microsoft.com → Billing → Licenses.

The emergency accounts don't need a license, so you don't have to change them.

For later: Pulumi will set the usage location on everyone listed in people.yaml, and licenses will be assigned through the infra-developers group. Adding a new infra developer then won't hit this error.
